# 🌐 Webflow Agent Skills — Полный Реестр и Руководство

Данная директория содержит **28 официально установленных Webflow Agent Skills** в экосистеме Antigravity CLI.

**Расположение в системе:**
- **Исполняемые файлы скиллов:** `/root/.agent/skills/`
- **Документация и справочники Obsidian:** `/root/obsidian/Vibe Design/Webflow/Webflow/Skills/`
- **MCP Сервер:** `@webflow/mcp-server` в `/root/mcp_config.json`

## 🛠️ Как задействовать Webflow Skills

Каждый скилл автоматически активируется при формулировании соответствующей задачи.

Примеры команд:
- **Аудит доступности**: *"Запусти accessibility audit для моего сайта Webflow"*
- **Массовое обновление CMS**: *"Обнови 10 постов в коллекции Блог"*
- **Файлы и верстка Figma**: *"Перенеси макет из Figma в Webflow"*
- **Деплой и публикация**: *"Проверь пре-деплой чек-лист и опубликуй сайт"*
