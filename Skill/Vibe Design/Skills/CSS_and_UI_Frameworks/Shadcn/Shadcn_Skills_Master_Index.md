# 🧱 Shadcn UI Skills

Пакет навыков для экосистемы Shadcn UI:

1. **Shadcn Component Discovery**: Автоматический поиск и подбор готовых компонентов Shadcn UI и сторонних реестров (Magic UI, Aceternity, Animate UI).
2. **Shadcn Component Review**: Аудит и проверка пользовательских компонентов на соответствие паттернам дизайна Shadcn и токенам.
3. **Shadcn Improve**: Комплексный разбор архитектуры UI компонентов и выработка плана улучшения.
