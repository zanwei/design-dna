# 🎨 Tailwind CSS Agent Skills — Реестр и Руководство

Данная директория содержит полное руководство и спецификации для работы с **Tailwind CSS v4 Engine**, дизайн-системами на основе токенов и галереей верстки UI-компонентов.

**Расположение в системе:**
- **Исполняемые файлы скиллов (CLI):**
  - `/root/.agent/skills/tailwind-v4/SKILL.md`
  - `/root/.agent/skills/tailwind-design-system/SKILL.md`
  - `/root/.agent/skills/tailwind-components/SKILL.md`
- **Документация и справочники Obsidian:** `/root/obsidian/Vibe Design/Skills/Tailwind/`

## 🛠️ Как задействовать Tailwind Skills

Скиллы автоматически подключаются при выполнении любых верстальных и дизайнерских задач в ИИ-чате.

**Примеры команд:**
- **Настройка Tailwind v4**: *"Настрой Tailwind CSS v4 с плагином Vite и кастомной темой @theme"*
- **Дизайн-система**: *"Создай палитру цветов и токены для темной темы в Tailwind"*
- **Верстка компонентов**: *"Сверстай Glassmorphism Hero секцию на Tailwind CSS"*
