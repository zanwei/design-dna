## 📚 Реестр Категорий и Скиллов

### 1. 🤖 AI Prototyping (`AI_Prototyping/`)
- **Stitch Suite** (`Stitch/`):
  - [[Stitch_Taste_Design]] — Семантическая дизайн-система и анти-шаблонный UI.
  - [[Stitch_Stitch_Loop]] — Автономный цикл итеративного прототипирования.
  - [[Stitch_Code_To_Design]] — Извлечение верстки из React/Vue/Vite в Stitch.
  - [[Stitch_Generate_Design]] — Генерация экранов и компонентов по текстовым промптам.
  - [[Stitch_React_Components]] — Конвертация дизайна Stitch в модульные компоненты Vite + React.
  - [[Stitch_Manage_Design_System]] — Управление токенами и ассетами в Stitch.

### 2. 🎬 Animations & Motion (`Animations_and_Motion/`)
- **GSAP Animations** (`GSAP/`):
  - [[GSAP_Core_Skill]] — Опорный API GSAP (tweens, easing, duration).
  - [[GSAP_Timeline_Skill]] — Последовательные анимации и таймлайны.
  - [[GSAP_ScrollTrigger_Skill]] — Скролл-анимации, параллакс и пиннинг.
  - [[GSAP_Performance_Skill]] — Оптимизация FPS, 60fps и исключение jank.
  - [[GSAP_React_Skill]] — Hook `useGSAP` и очистка контекста в React/Next.js.
- **Genjutsu Suite** (`Genjutsu/`):
  - [[Genjutsu_Cast_Skill]] — Иллюзии микро-взаимодействий для Web, Android, iOS.
  - [[Genjutsu_Paint_Skill]] — Полная визуальная концептуализация UI.
  - [[Genjutsu_CSS_Native]] — Scroll-driven animations и View Transitions.
  - [[Genjutsu_Canvas_Generative]] — Частицы, flow fields и Canvas 2D.
- **Motion Design** (`Motion_Design/`):
  - Руководство по физике движения, микро-анимациям, таймингу и Disney principles.
- **ThreeJS 3D** (`ThreeJS/`):
  - 3D-сцены, освещение, шейдеры и интерактивный WebGL/WebGPU.

### 3. 🧱 Design & UI (`Design_and_UI/`)
- **UI UX Pro Max** (`UI_UX_Pro_Max/`):
  - База из 84 стилей, 192 палитр, 74 шрифтовых пар и 98 UX-правил.
- **Shadcn UI** (`Shadcn/`):
  - Поиск готовых блоков в внешних реестрах (`shadcn-component-discovery`).
  - Аудит доступности (WCAG) и стандартов (`shadcn-component-review`).
  - Миграция Radix на Base UI (`migrate-radix-to-base`).
- **Tailwind CSS** (`Tailwind/`):
  - Руководство по Tailwind CSS v4 engine и токены CSS-variables.
- **Awesome Design** (`Awesome_Design/`):
  - Подборки премиум ассетов, иконпаков и прототипирования.

### 4. 📱 Platforms & Mobile (`Platforms_and_Mobile/`)
- **Webflow Suite** (`Webflow/`):
  - **Figma to Webflow** — Прямой перенос верстки Figma в Webflow MCP.
  - **Client-First & Flowkit Naming** — CSS именование Finsweet v2/v3 и Flowkit.
  - **Code Components & Dev** — Разработка и деплой React компонентов в Webflow.
  - **CMS Management** — Массовое управление CMS, сжатие WebP/AVIF.
  - **Audits & Quality** — SEO, доступность WCAG, проверка ссылок и логи активности.
- **CosmicMind Material** (`CosmicMind_Material/`):
  - Архитектура мобильных компонентов Swift / iOS и Motion анимации.

## 🛠️ Как задействовать Vibe Design Skills

Вы можете использовать следующие естественные инструкции в **Antigravity CLI**:

1. *"Ссоздай лендинг с эффектным параллаксом и ScrollTrigger анимацией через GSAP"*
2. *"Найди готовые компоненты сайдбара и формы в реестрах Shadcn UI через `shadcn-component-discovery`"*
3. *"Сгенерируй семантический `DESIGN.md` файл по правилам anti-AI-slop с помощью `stitch-taste-design`"*
4. *"Проверь accessibility и структуру классов в Webflow с помощью `accessibility-audit` и `client-first-naming`"*
