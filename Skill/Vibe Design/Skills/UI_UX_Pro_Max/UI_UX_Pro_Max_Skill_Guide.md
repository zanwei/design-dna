# 🔍 UI/UX Pro Max Skill Guide

Исполняемый скилл `ui-ux-pro-max` позволяет ИИ-агенту запрашивать оптимальные параметры дизайна под конкретную индустрию и стек.

---

## 💻 Поисковый скрипт Python

Скилл оснащен встроенной поисковой базой:
`/root/.agent/skills/ui-ux-pro-max/src/ui-ux-pro-max/scripts/search.py`

### Команда генерации дизайн-системы:
```bash
python /root/.agent/skills/ui-ux-pro-max/src/ui-ux-pro-max/scripts/search.py "SaaS analytics dark mode" --design-system
```
