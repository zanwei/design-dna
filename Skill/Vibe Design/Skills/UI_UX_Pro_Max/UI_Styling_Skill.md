# 🎨 UI Styling Skill Guide

Скилл `ui-styling` отвественен за визуальные эффекты и трендовые стили:
- **Glassmorphism**: Блюры (`backdrop-filter: blur(16px)`), белые полупрозрачные границы.
- **Aurora UI**: Плавающие размытые световые пятна (Aurora Orbs).
- **Neumorphism**: Мягкие тени высоты `box-shadow`.
- **Dark Mode**: Глубокие фоны `#0B0F17`, `#0F172A`.
