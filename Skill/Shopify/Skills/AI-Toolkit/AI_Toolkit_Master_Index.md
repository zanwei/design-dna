# 🛠️ Shopify AI Toolkit — Master Index

Официальный набор агентных скиллов от инженеров **Shopify** ([github.com/Shopify/Shopify-AI-Toolkit](https://github.com/Shopify/Shopify-AI-Toolkit)), адаптированный под Antigravity CLI для разработки тем, приложений, метаданных и интерфейсов.

---

## 📂 Скиллы и Компоненты в папке AI-Toolkit

| Имя скилла (Markdown) | Описание и сфера применения |
| :--- | :--- |
| **[[shopify-liquid]]** | Валидация Liquid, создание секций, сниппетов, `theme.json`, dynamic blocks |
| **[[shopify-dev]]** | Shopify CLI workflows, инициализация проектов, локальный dev-сервер |
| **[[shopify-use-shopify-cli]]** | Команды `shopify theme dev`, `shopify store execute`, сборка и выгрузка тем |
| **[[shopify-custom-data]]** | Схемы Metafields и Metaobjects (настраиваемые поля для товаров) |
| **[[shopify-functions]]** | Бекэнд-логика на Rust/Wasm (скидки, checkout validation, delivery rules) |
| **[[shopify-hydrogen]]** | Headless-магазины на React / Remix / Hydrogen |
| **[[shopify-admin]]** | GraphQL/REST Admin API операции и мутации |
| **[[shopify-storefront-graphql]]** | Прямые GraphQL запросы к Storefront API для кастомных интерфейсов |
| **[[shopify-polaris-admin-extensions]]** | Admin UI Extensions на базе компонентов Polaris |
| **[[shopify-polaris-checkout-extensions]]** | Расширения оформления заказа (Checkout UI Extensions) |
| **[[shopify-polaris-app-home]]** | Встроенные интерфейсы приложений в админке Shopify |
| **[[shopify-polaris-customer-account-extensions]]** | Расширения для кабинета покупателя |
| **[[shopify-customer]]** | Customer Account API |
| **[[shopify-app-store-review]]** | Чеклист проверки приложения перед публикацией в Shopify App Store |
| **[[shopify-partner]]** | Partner API для управления рефералами и приложениями |
| **[[shopify-payments-apps]]** | Payments Apps API для интеграции платежных шлюзов |
| **[[shopify-pos-ui]]** | UI компоненты для розничной торговли (Shopify POS) |
| **[[shopify-shopifyql]]** | ShopifyQL для аналитических отчетов и выгрузки показателей продаж |
| **[[shopify-onboarding-dev]]** | Руководство по старту разработки под Shopify |
| **[[shopify-onboarding-merchant]]** | Руководство по созданию и настройке магазина для мерчантов |
| **[[ucp]]** | Universal Commerce Protocol CLI инструмент |
