# 🛍️ Shopify Agent Skills & Automation Registry

Данный каталог содержит руководства и специализированные навыки для разработки, управления и автоматизации интернет-магазинов на **Shopify** (включая бренд **Awruma** `awruma.myshopify.com`) через **Shopify MCP Server** (`shopify-mcp`), официальные наборы **Shopify AI Toolkit**, **Shopify Agent Skills**, **Dragnoir Agent Skills**, **Shopify App Build & Design Guidelines**, **Shopify SEO & GEO Optimization**, **SurfaceKit AEO Skills**, **ClaudeKit Shopify Master Skill**, **Shopify Custom Data Architecture** и **Liquid Theme Standards & Accessibility** из реестра [MCP Market](https://mcpmarket.com/tools/skills/official/shopify/all).

## 🛠️ Как задействовать Shopify MCP Tools & Skills

В рамках Antigravity CLI вы можете давать прямое поручение ИИ-агенту:
* *"Проверь тему Sleek на соответствие стандартам доступности WCAG 2.2 и фокуса в корзине через `liquid-theme-accessibility`"*
* *"Создай дефиниции метаполей и метаобъектов для товаров Awruma в формате `shopify.app.toml` с помощью `shopify-custom-data-architecture`"*
* *"Инициализируй проект нового Shopify приложения через `shopify_init.py` из `ClaudeKit-Skills`"*
